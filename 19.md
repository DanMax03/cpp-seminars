# А что такое `operator new/delete`?

Всё это время скрывалась часть истины - `operator new/delete` состоит из двух частей. Строго говоря:
 - `operator new/delete` как действительно оператор, функция - её вызов отвечает за аллокацию/деаллокацию памяти
 - `placement new/delete` - часть, ответственная за конструирование/деконструирование объектов

## Глобальная перегрузка `operator new/delete`

`operator new/delete` - единственная часть, которую мы можем переопределить у данного оператора. Перегрузка может быть
 - Глобальной (затронет все выражения `new/delete`)
 - Локальной (для классов. Будут затронуты только `new/delete` выражения с соответствующим классом)

**Пример:**
```cpp
#include <iostream>
#include <vector>

void* operator new(size_t n) {
    std::cout << n << " bytes allocated\n";
    return malloc(n);
}

void operator delete(void* ptr) {
    std::cout << "called delete\n";
    free(ptr);
}

int main() {
    std::vector<int> a;

    for (int i = 0; i < 50; ++i) {
        a.push_back(i);
    }
}
```

## Устройство стандартных `operator new[]/delete[]`

**Пример:** оказывается, `new[]/delete[]` просто ссылаются на `new/delete`
```cpp
#include <iostream>

void* operator new(size_t n) {
    std::cout << n << " bytes allocated\n";
    return malloc(n);
}

void operator delete(void* ptr) {
    std::cout << "called delete\n";
    free(ptr);
}

int main() {
    int* xs = new int[100];
    delete[] xs;

    return 0;
}
```

**Пример:** а как `new[]/delete[]` понимает, сколько конструкторов/деструкторов вызвать? Эту информацию приходится сохранять
```cpp
#include <iostream>

void* operator new(size_t n) {
    std::cout << n << " bytes allocated\n";
    return malloc(n);
}

void operator delete(void* ptr) {
    std::cout << "called delete\n";
    free(ptr);
}

void* operator new[](size_t n) {
    std::cout << n << " bytes[] allocated\n";
    return malloc(n);
}

void operator delete[](void* ptr) {
    std::cout << "called delete[]\n";
    free(ptr);
}


int main() {
    int* xs = new int[100];

    std::cout << xs << std::endl;

    delete[] xs;
}
```

**Пример:** об этом стоит всегда помнить, что `new[]` возвращает сдвинутый указатель
```cpp
class X {
public:
    X() : a(new int) {}
    ~X() {
        delete a;
    }
private:
    int* a{nullptr};
};

int main() {
    int* x = new X[1];
    x->~X();
    operator delete[](x);
}
```

## Остальные перегрузки `operator new/delete`

Существует [огромное количество перегрузок этих операторов](https://en.cppreference.com/w/cpp/memory/new/operator_new)

**Важно:** любая перегрузка `operator new` должна сопровождаться аналогичной перегрузкой `operator delete` с теми же дополнительными параметрами. Иначе - UB

**Пример:**
```cpp
struct MyTag {};

void* operator new(size_t n, MyTag) {
    std::cout << n << " bytes(MyTag) allocated\n";
    return malloc(n);
}

void operator delete(void* ptr, MyTag) {
    std::cout << "called delete(MyTag)\n";
    free(ptr);
}

int main() {
   int* x = new(MyTag{}) int{10};
   std::cout << *x << std::endl;
   delete x;  // UB
}
```

**Пример:** компилятор может самостоятельно звать наши перегрузки, если это необходимо
```cpp
struct MyTag {};

void* operator new(size_t n, MyTag) {
    std::cout << n << " bytes(MyTag) allocated\n";
    return malloc(n);
}

void operator delete(void* ptr, MyTag) {
    std::cout << "called delete(MyTag)\n";
    free(ptr);
}

struct S {
    S() {
        throw 1;
    }

    ~S() {
    }
};

int main() {
    try {
        S* s = new(MyTag{}) S;
    }
    catch (...) {
        // compiler automatically called operator delete(s, MyTag{})
        std::cout << "magic!" << std::endl;
    }
}
```

**Пример:** это касается в том числе деконструирования
```cpp
struct MyTag {};

void* operator new(size_t n, MyTag) {
    std::cout << n << " bytes(MyTag) allocated\n";
    return malloc(n);
}

void operator delete(void* ptr, MyTag) {
    std::cout << "called delete(MyTag)\n";
    free(ptr);
}

struct S {
    inlint static int count = 0;

    S() {
        if (++count == 5) {
            throw 1;
        }
    }

    ~S() {
    }
};

int main() {
    try {
        S* s = new(MyTag{}) S[10];
    }
    catch (...) {
        // compiler automatically called destructors
        // compiler automatically called operator delete(s, MyTag{})
        std::cout << "magic!" << std::endl;
    }
}
```

**Пример:** локальная перегрузка делается тривиально
```cpp
struct S {
    void* operator new(size_t n) {
        std::cout << n << " bytes(from S) allocated\n";
        return malloc(n);
    }

    void operator delete(void* ptr) {
        std::cout << "Called delete(from S)\n";
        free(ptr);
    }
};

int main() {
    S* s = new S;
    delete s;
}
```

**Важно:** предыдущий пример должен вызвать недоумение. Конечно же, перегрузки `new/delete` не являются методами классов! Для них по-умолчанию дописывается слово `static`.

## `destroying delete` (since C++20)

**Задача:** запретить классу создаваться на куче, при этом разрешить создаваться на стэке (и любой заранее выделенной памяти)
**Решение:** `void* operator new(size_t n) = delete;`

**Задача:** запретить классу создаваться на стэке, при этом разрешить создаваться на куче
**Решение:** До C++20 решить эту задачу адекватным образом было нельзя, потому что лучший подход здесь - это сделать деструктор приватным. Но тогда неявно блокируется в том числе создание на куче,
потому что позвать деструктор извне никак не получится. Поэтому комитет придумал очередной костыль - `void operator delete(void* ptr, std::destroying_delete_t)`. Эта функция должна отвечать не только за
деаллокацию памяти, но и за вызов деструктора

## `operator new[]/delete[]` с наследниками

**Пример:** даже если наследование виртуальное, `new[]/delete[]` никак не может понять, какой размер у наследника и на каких адресах вызывать деструкторы
```cpp
struct Base {
    Base() {
        std::cout << "Base()\n";
    }

    ~Base() {
        std::cout << "~Base()\n";
    }
};

struct Derived : Base {
    int x{0};

    Derived() {
        std::cout << "Derived()\n";
    }

    ~Derived() {
        std::cout << "~Derived()\n";
    }
};

int main() {
    Base* b = new Derived[10];
    delete[] b;
}
```

## `alignof` и `alignas`

Точно так же, как есть оператор `sizeof`, есть аналогичный ему `alignof`.

`alignas` позволяет указывать выравнивание самостоятельно.

Максимально доступное выравнивание (и то, которое гарантируется `std::malloc`) выражено через тип `std::max_align_t`

**Пример:**
```cpp
#include <cstddef>
#include <iostream>

int main() {
    std::cout << alignof(std::max_align_t) << std::endl;
}
```

## Copy elision

**Пример:**
```cpp
#include <iostream>

struct S {
    S(const char*) {
        std::cout << "S(const char*)\n";
    }

    S(const S&) {
        std::cout << "S(const S&)\n";
    }

    S(S&&) {
        std::cout << "S(S&&)\n";
    }

    ~S() {
        std::cout << "~S()\n";
    }
};

int main() {
    S s = S("abc");  // 1 constructor!!!
}
```

Однако, если заменить `S("abc")` на `std::move(S("abc"))`, то компилятор создаст промежуточную строку, потому что значение превратилось из prvalue в xvalue.

Copy elision - для prvalue не создаются (в реальности) объекты.

Temporary materialization - создание xvalue из prvalue.

**Замечание:** это не *временная материализация*, а материализация *временного объекта*

## RVO

RVO - Return Value Optimization - частный случай copy elision в контексте `return`-выражений.

### NRVO

NRVO - Named RVO

**Пример:** NRVO сильнее copy elision, потому что 
```cpp
S f() {
   S s = "ololo"; 
   return s;
}

int main() {
    S s = f();
}
```

**Пример:** NRVO не работает с аргументами функции
```cpp
S f(S s) {
    return s;
}
    

int main() {
    S s = "ololo";
    S s2 = f(s);
}
```

**Пример:** писать `std::move` вручную можно, если возвращается не значение
```cpp
S f(S&& s) {
    return std::move(s);  // s is S&&, it's okay
}

int main() {
    S s = "ololo";
    S s2 = f(std::move(s));
}
```
